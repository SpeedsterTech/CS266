# Bash Reference

## Navigation
- `pwd` - print work directory.
- `ls` - list files in current directory.
  - `ls -l` - all files.
  - `ls -t` - sort files by time
  - `ls --help` - for description for ls options
  - `man ls` - prints ls manuel
  - `ls -F` - adds symbol to file or directory for indication
    - `/` for directory
    - `@` for link
    - `*` for executable file  
- `cd` - Change directory
  - `cd ..` - go back one directory
- `mkdir [name] ` - makes a directory
  - `mkdir -p` - makes directory with nested folders in a single sweep
- `nano` - text file editor and creater
