# Bash Reference

## Navigation
- `pwd` - print work directory.
- `ls` - list files in current directory.
  - `ls -l` - all files.
  - `ls -t` - sort files by time
  - `ls -F` - adds symbol to file or directory for indication
    - `/` for directory
    - `@` for link
    - `*` for executable file
